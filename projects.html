Monte Carlo Simulation

This Monte Carlo Simulation was created with python. I created the Monte Carlo Simulation in my first year of university. The purpose of this simulation was to prove the probability of winning. This was done by creating a loop in python to repeat the simulation a number of 'runs' stated by the user. Then once all the runs are completed, the probability of winning is calculated as a percentage.

This text analyser would calculate the total number of tokens, the frequency count of a particular token, the normalised frequency of the particular token, the total number of sentences and a list of sentences that contain the particular token in the text file.

Snack Man

I created a game called Snack Man using HTML, CSS, and JavaScript. The game features a point counter and three lives for the player. When the player loses all their lives, a game-over animation is triggered. After the game ends, the player is prompted to enter their name, and their score is saved to local storage and displayed on a leaderboard.

F1 Flux

I led an AI and Data Science project with FEMETRONICS by utilising a real life F1 dataset to analyse model fairness. We demonstrated through data analysis that an initial AI model exhibited bias against specific Formula 1 teams. Finally, we use mitigated bias by implementing a strategy of training separate AI models for distinct team groupings, improving overall model fairness and accuracy.

Analysis and Modelling Houseprice Dataset

I analysed a housing dataset using machine learning and data visualisation to identify market trends and generate insights. I cleaned and preprocessed the data, then developed a regression model to predict house prices from property features. I also applied clustering to group houses into price categories and built a classification model to predict those categories when exact prices were unavailable. The project combined technical modelling with clear business focused explanations, helping translate data insights into practical recommendations.

Deep learning Model for Palm Recognition

I developed a deep learning palm recognition system using Python, TensorFlow/Keras, and image preprocessing techniques to classify registered users from close-up palm images. The project involved creating and preparing a custom dataset, designing and training a multi-class image classifier, and evaluating its performance using accuracy metrics and live camera testing. I also considered practical issues such as unknown palm detection, dataset bias, and ethical challenges in biometric system design.
